# Code Visualizer Frontend

A Pygame-based frontend shell for a Semester 3 IT Engineering code visualizer.

The application provides an editable Python code panel on the left and a reserved animation/output panel on the right. Gemini API integration, JSON animation generation, and visualization playback will be added in a later phase.

## Requirements

- Python 3.9 or newer
- Pygame
- Tkinter

Tkinter is normally included with the official Python installer for Windows.
